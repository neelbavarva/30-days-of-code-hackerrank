## About

[30 Days of Code](https://www.hackerrank.com/domains/tutorials/30-days-of-code) is a HackerRank tutorial that introduces one programming concept per day, from basic data types to generics, binary search trees and bitwise operations. This repository has one solution file per day.

## Challenges

| Days | Topics |
| --- | --- |
| 0 – 5 | Hello World, data types, operators, conditionals, class vs. instance, loops |
| 6 – 11 | String processing, arrays, dictionaries and maps, recursion, binary numbers, 2D arrays |
| 12 – 17 | Inheritance, abstract classes, scope, linked lists, exceptions |
| 18 – 23 | Queues and stacks, interfaces, sorting, generics, binary search trees, level-order traversal |
| 24 – 29 | More linked lists, running time and complexity, nested logic, testing, regex, bitwise AND |

## Running a solution

Each file is a complete program that reads from standard input, like on HackerRank. With Java 11 or later you can run a file directly:

```bash
echo "Welcome to 30 Days of Code" | java "Day 0 - Hello, World.java"
```
